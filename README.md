# Парсер ThermoML VLE

Рабочая версия для практической работы № 2. Парсер читает ThermoML JSON, собирает значения каждого `NumValues` в отдельную точку и сохраняет источник, фазу, компонент и происхождение значений. Для бинарных смесей он приводит доли жидкости и пара к одному порядку компонентов и отдельно отмечает доли, вычисленные по нормировке.

## Запуск

Нужен Python 3.12. Сторонних зависимостей нет. Выполняйте команды из папки с `main.py`.

```powershell
py -B main.py --block 4 --output extracted_points.csv
py -B -m unittest -v test_thermoml
```

В Linux и macOS вместо `py` используйте `python3`. Для `--output` укажите имя нового файла. Без `--block` программа обрабатывает все блоки входного JSON.

Встроенный пример `data/j.fluid.2004.02.021.json` содержит 225 записей из пяти блоков. В бинарном блоке 4 — 99 точек. Измеренный состав пара в контрольном файле отсутствует.

## Каталог первой пары

```powershell
py -B main.py --file "архив/подпапка/источник.json" --root "архив" --catalog "каталог" --block 4 --output extracted_points.csv
```

Укажите один и тот же корень архива при формировании каталога и при запуске парсера. Тогда `source_file` будет одинаковым в обоих результатах. В папке каталога должны быть `datasets.csv` и `dataset_components.csv`. В качестве `--catalog` также можно передать путь к `datasets.csv`, а таблицу связей указать через `--dataset-components`.

`dataset_id` вычисляется из относительного пути и исходного номера блока, `record_id` — из `dataset_id` и номера `NumValues` с единицы. `component_id` берётся из InChIKey, а при его отсутствии используются предусмотренные регламентом запасные варианты. Компоненты сортируются по `component_id`, а `mixture_id` вычисляется из этих ID, соединённых через `;`. DOI сохраняется из `Citation.sDOI`. Выгрузка использует UTF-8 с BOM, разделитель `;` и списки фаз и идентификаторов через `;`.

## Статус

`extracted_points.csv` — промежуточная выгрузка для проверки вторым студентом. Автоматический отбор бинарных VLE-блоков, нормализация произвольных единиц, классификация и итоговые таблицы ещё предстоят. Совместимость со схемой каталога проверена на тестовом примере. Для проверки на реальных данных нужны CSV первой пары.
