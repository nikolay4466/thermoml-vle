# Парсер ThermoML VLE

## Как запустить

Откройте терминал в папке с `main.py`. Нужен Python 3.12. Устанавливать дополнительные библиотеки не нужно.

```powershell
py -B main.py --block 4
```

Команда обработает блок 4 из контрольного файла. Чтобы обработать все блоки, уберите `--block 4`. Чтобы сохранить результат, добавьте `--output extracted_points.csv` и укажите имя файла, которого ещё нет. Для своего JSON укажите `--file` и `--root` (корень архива). Каталог можно подключить через `--catalog`.

Команда для запуска тестов — `py -B -m unittest -v test_thermoml`.
